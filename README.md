# Revisão de POO em Java

Este repositório reúne minha frustração por não diferenciar direito instância de classe, variável local e como fazer construtores decentes.
É um exercício próprio de revisão para eu criar vergonha na cara e, de quebra, fazer algum progresso com Programação Orientada a Objetos.


## Conteúdos praticados

- Classes e objetos
- Instâncias
- Atributos
- Variáveis locais
- Construtores
- Métodos
- Encapsulamento
- Estruturas condicionais
- Operadores lógicos
- Validação de dados
- Manipulação do estado de objetos


## Exercícios

### Conta Bancária

Sistema simples de conta bancária com operações de depósito, saque, exibição de dados e validação de operações inválidas.

### Produto e Estoque

Sistema simples de produtos e controle de estoque, permitindo adicionar e remover unidades, além de exibir informações do produto e da quantidade disponível.


## Objetivo

Além de servir como material de revisão, este repositório também existe para me motivar a continuar estudando e não desanimar por ainda não conhecer 400 termos técnicos diferentes, considerando que este é meu primeiro contato mais sério com POO.
A ideia é continuar adicionando novos exercícios conforme eu for revisando e aprendendo novos conceitos.

Prepare a pipoca e o lencinho para as lágrimas.
