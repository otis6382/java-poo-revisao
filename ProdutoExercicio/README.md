## PT-BR

Atividade de revisão de uma aula de POO (Programação Orientada a Objetos), o objetivo foi desenvolver um sistema simples de produtos e estoque, permitindo adicionar e remover unidades, além de exibir os dados do produto.

## EN

Review exercise from an OOP (Object-Oriented Programming) class, the main objective was to create a simple product and inventory system, allowing stock to be added or removed and product information to be displayed.
